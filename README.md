# LuxSpace

LuxSpace is a furniture e-commerce application built on the **Laravel + Livewire Starter Kit**. It ships with a customer-facing storefront for browsing and buying furniture, and a role-protected admin dashboard for managing products, categories, discounts, and transactions.

## Features

### Storefront
- Home page with featured products
- Product catalog and product detail pages
- Shopping cart
- Checkout with address and courier selection
- Order history for authenticated users
- Payment success and failure pages

### Admin Dashboard (`/dashboard`, requires the `admin` role)
- Product management with image galleries
- Category management
- Discount management (product-level and transaction-level, percentage or fixed amount)
- Transaction management

### Integrations
- **Xendit** for payment sessions and webhook callbacks
- **RajaOngkir** for shipping cost and courier lookup
- **Resend** for transactional email
- **Intervention Image** for image handling

### Authentication
- Laravel Fortify with two-factor authentication
- Role-based access control (`role:admin`)

## Installation

Clone the repository and install dependencies:

```bash
git clone <repository-url> luxspace2
cd luxspace2
```

The quickest way to install everything is the provided setup script:

```bash
composer setup
```

This runs `composer install`, copies `.env.example` to `.env`, generates the application key, runs migrations, installs npm dependencies, and builds front-end assets.

### Manual Installation

If you prefer to run the steps individually:

```bash
composer install
cp .env.example .env
php artisan key:generate
php artisan migrate
npm install
npm run build
```

## Setup / Configuration

After installation, review the `.env` file and set the values relevant to your environment.

| Variable | Description |
| --- | --- |
| `APP_NAME` | Application name |
| `APP_ENV` | Application environment (`local`, `production`, ...) |
| `APP_KEY` | Application encryption key (generated by `php artisan key:generate`) |
| `APP_URL` | Base URL of the application |
| `DB_CONNECTION` | Database driver (`sqlite` by default, or `mysql`) |
| `DB_*` | Database host, port, name, username, and password (when using MySQL) |
| `RAJA_ONGKIR_KEY` | API key for RajaOngkir shipping lookups |
| `XENDIT_KEY` | API key for Xendit payments |
| `XENDIT_RETURN_HOST` | Public host used as the Xendit return URL (for example an ngrok URL) |
| `RESEND_API_KEY` | API key for Resend transactional email |

## Database

Run the migrations:

```bash
php artisan migrate
```

Optionally seed sample data (discounts):

```bash
php artisan db:seed
```

The default database connection is SQLite, stored at `database/database.sqlite`. To use MySQL instead, set `DB_CONNECTION=mysql` and the related `DB_*` variables in `.env`.

## Running Locally

Start the development environment with a single command. This runs the PHP server, the queue listener, and Vite concurrently:

```bash
composer dev
```

Alternatively, run the services separately:

```bash
php artisan serve
php artisan queue:listen --tries=1
npm run dev
```

## Testing and Linting

```bash
composer test        # clear config cache, run lint check, then the test suite
composer lint        # fix code style with Pint
composer lint:check  # check code style without fixing
composer ci:check    # run the test suite for CI
```

## Payment Webhook

Xendit sends payment callbacks to:

```
POST /webhooks/xendit
```

For local development, expose your application to the internet (for example with ngrok) and set `XENDIT_RETURN_HOST` to the public host so payment redirects resolve correctly.
